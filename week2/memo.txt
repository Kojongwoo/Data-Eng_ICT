# CTE(With 절)
WITH 이름 AS (쿼리)로 만드는 임시 결과, 해당 쿼리가 도는 동안만 존재함.
서브 쿼리의 단점(안쪽부터 거꾸로 읽어야 함, 같은 집계를 여러 번 적게 됨)을 보완하기 위한 대체제
CTE와 Window Function은 데이터 엔지니어가 가장 자주 사용하는 SQL 기능으로, 분석 쿼리이다.
