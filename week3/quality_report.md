# 3주차 산출물 — 데이터 품질 리포트

## 1. 대상
- 원본: `orders.csv` (1,015행) — 3-1에서 고정 시드로 생성
- 정제 결과: `orders_clean.parquet` (1,000행)
- 파이프라인: `clean_orders.py` (DuckDB 추출 + Pandas 정제)
- 주문 ID 컬럼명: 원본에서는 `orders_id`로 저장되어 있음

## 2. 품질 지표 전후 비교
| 지표 | before | after |
|---|---:|---:|
| 행 수 | 1,015 | 1,000 |
| 주문 ID 중복 (`orders_id`) | 15 | 0 |
| `price` 결측 | 30 (2.96%) | 0 |
| `category` 고유값 | 5 | 4 |

## 3. 처리 내용과 근거
| 문제 | 처리 | 근거 |
|---|---|---|
| `category` 앞뒤 공백 20건 | `str.strip()` | `' 식품 '`을 `'식품'`으로 통일해 별개 카테고리로 집계되는 문제를 해결함 |
| `order_date` 자료형 | `pd.to_datetime()` | CSV를 Pandas로 읽을 때 문자열로 들어오는 주문일을 날짜형으로 변환해 후속 처리를 일관되게 함 |
| 주문 ID 중복 15건 (`orders_id`) | `drop_duplicates(subset='orders_id', keep='first')` | 같은 주문이 매출 집계에 중복 반영되는 것을 방지함 |
| `price` 결측 30건 | 중복 제거 후 중앙값으로 보정 | 결측률이 2.96%이며 중앙값은 극단값의 영향을 덜 받음. 중복 제거 전후 중앙값이 달라(101,000 → 100,500) 처리 순서를 고정함 |

## 4. 고치지 않은 것
- 정제 후 0 이하 가격·수량과 미지 카테고리는 발견되지 않아 추가 조치하지 않음

## 5. 검증
- 재실행 검증: 같은 원본을 두 번 정제한 결과가 동일함 (`DataFrame.equals()` → `True`)
- 교차 검증: DuckDB 재집계 결과, 정제본은 1,000행·중복 0건·가격 결측 0건·카테고리 4종으로 Pandas 결과와 일치함
- 유효성 검사: 0 이하 가격 0건, 0 이하 수량 0건, 미지 카테고리 0건
- 검사기 자체 검증: 테스트 데이터에 가격 `-1`과 카테고리 `알수없음`을 넣어 각각 1건씩 검출함

## 6. 남은 과제
- 미래 날짜와 필수 컬럼·자료형 검사 추가
- 원본의 `orders_id` 컬럼명을 후속 데이터와 일관되게 맞출지 검토
